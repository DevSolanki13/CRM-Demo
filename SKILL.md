# Skill Finder & Activator

This skill helps discover, match, and recommend the best agent skills for any task, prompt, technology stack, or design workflow.

## Objectives
1. **Discover & Recommend**: Map user requests to installed or available skills.
2. **Auto-Trigger Guidance**: Identify the exact skill name, description, and key capabilities to fulfill user intent.
3. **Skill Ecosystem Navigation**: Help the agent and user understand which skill handles design, motion, frontend polish, code quality, or architecture.

## Skill Directory Index

### 1. Motion & Animation Skills (Emil Kowalski)
- `animate`: Build purposeful web animations, transitions, and motion components from scratch.
- `animation-vocabulary`: Reverse-lookup glossary translating vague descriptions ("the bouncy popover") into exact motion terms.
- `apple-design`: Apple's fluid interface principles, spring physics, interruptible gestures, optical sizing, and translucent depth.
- `emil-design-eng`: Craft philosophy for micro-interactions, responsive button scale, easing curves (`cubic-bezier`), and fast perceived performance.
- `find-animation-opportunities`: Search codebases for seams that need motion and filter out unnecessary animations.
- `improve-animations`: Audit existing motion code and generate structured, self-contained implementation plans.
- `pick-ui-library`: Guide selection of component libraries based on motion, accessibility, and framework fit.
- `prototype`: Rapidly build interactive prototypes to test feel and interaction before production code.
- `review-animations`: Perform granular reviews of UI transitions, curves, durations, and spring values.

## Matching Protocol
When a user asks:
- *"Which skill should I use for X?"*
- *"Help me find a skill for Y"*
- *"Recommend skills for my project"*

1. Identify the primary domain (Motion, Visual Style, UX Review, Code Quality).
2. Recommend 1 to 3 specific skills by exact name.
3. Show example trigger prompts for how the user can invoke them.
